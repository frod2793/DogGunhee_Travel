🚀 프로젝트 기술 명세서
개요
본 프로젝트는 유연한 라이브 서비스, 최적화된 성능, 안전한 데이터 관리라는 세 가지 핵심 목표를 가지고 개발한 모바일 게임입니다.

Addressable Asset을 도입하여 앱 업데이트 없이 콘텐츠를 추가하는 라이브 서비스 환경을 구축했으며, 오브젝트 풀링과 팩토리 패턴으로 대규모 전투에서도 안정적인 프레임워크를 확보했습니다. 또한, 하이브리드 암호화와 서버 연동을 통해 사용자의 데이터를 위변조로부터 안전하게 보호하는 데 중점을 두었습니다.

주요 기술 및 구현 내용
🌐 유연한 라이브 서비스 및 콘텐츠 관리
라이브 업데이트 환경 구축: Addressable Asset 시스템을 도입하여 캐릭터, 스테이지 등 모든 게임 리소스를 원격으로 관리합니다. 이를 통해 스토어 업데이트 없이 신규 콘텐츠를 즉시 패치할 수 있습니다.

초기 설치 용량 최소화: 핵심 리소스만 앱에 포함하고 나머지는 필요할 때 원격으로 다운로드하여, 사용자의 초기 설치 부담을 크게 줄였습니다.

끊김 없는 비동기 로딩: Unity에 최적화된 UniTask를 활용하여 에셋 로딩 파이프라인을 구축했습니다. 전투 중에도 프리징 현상 없이 필요한 리소스를 실시간으로 불러와 부드러운 사용자 경험(UX)을 제공합니다.

⚡ 대규모 전투를 위한 런타임 성능 최적화
고성능 오브젝트 풀링: 뱀파이어 서바이버즈 장르의 특성상 화면에 등장하는 수많은 오브젝트로 인한 성능 저하를 막기 위해, Unity의 ObjectPool API 기반의 최적화 시스템을 설계했습니다.

GC Spike 원천 차단: 오브젝트의 생성(Instantiate)과 파괴(Destroy) 호출을 최소화하고, 오브젝트 풀이 생명주기를 직접 관리하도록 하여 가비지 컬렉션(GC)으로 인한 프레임 드랍을 원천적으로 억제했습니다.

🏗️ 견고하고 확장 가능한 아키텍처
유연한 오브젝트 생성 (팩토리 패턴): **팩토리 패턴(Factory Pattern)**을 적용하여 오브젝트를 '생성하는 코드'와 '사용하는 코드'를 명확히 분리했습니다. 그 결과, 신규 몬스터나 아이템을 추가할 때 기존 코드에 미치는 영향을 최소화하여 유지보수성과 확장성을 크게 높였습니다.

효율적인 데이터 관리: Scriptable Object를 적극 활용하여 게임의 핵심 데이터를 관리하고 메모리 사용을 최적화했으며, Singleton 패턴으로 데이터 접근의 일관성과 편의성을 확보했습니다.

🛡️ 안전한 데이터 관리 및 보안
데이터 위변조 방지 (하이브리드 암호화): 로컬에 저장된 사용자 데이터(재화, 아이템 등)의 위변조를 막기 위해 AES-256과 RSA를 결합한 하이브리드 암호화 시스템을 구현했습니다.

데이터: 빠른 속도를 위해 AES-256 대칭키로 암호화.

암호화 키: 이 AES 키 자체는 RSA 공개키로 다시 암호화하여 안전하게 관리.

서버를 통한 데이터 영속성 확보: 사용자의 중요 데이터는 JSON으로 변환 후 뒤끝(TheBackend.io) 서버에 백업 및 복원됩니다. 이를 통해 로컬 데이터가 조작되더라도 서버의 데이터로 복구하여 치팅을 방지하고 자산을 안전하게 보호합니다.

🚀 사용자 인증
간편 로그인: 게스트, GPGS, 토큰 기반 자동 로그인 등 다양한 인증 방식을 지원하여 사용자 접근성을 높였습니다.
